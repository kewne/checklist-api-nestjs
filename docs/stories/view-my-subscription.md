# View My Subscription

**Status**: NEW

As a user, I want to see the state of my subscription so that I can understand whether my subscription is active and when it will renew or end.

## Acceptance Criteria

- An authenticated user can view their own current subscription state.
- When a subscription exists, the user can see its current status and associated plan.
- When a renewal or end date is defined, the user can see that date and whether it represents renewal or the end of the subscription.
- A user without a subscription is clearly informed that they have no subscription.
- Subscription information is accessible only to the user it belongs to.
- If subscription information cannot be retrieved, the user is informed that it is unavailable rather than being told they have no subscription.
- Viewing subscription information does not change the subscription.
